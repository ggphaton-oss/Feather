# Feather

A tiny, fast, private browser for Android. No account, no tracking, no analytics.
Everything (tabs, bookmarks, history, settings) is stored on the device only.

**Features:** multi-tab with session restore, private tabs, smart address bar with 6 search engines,
speed-dial home page from your bookmarks, bookmarks and history, ad/tracker blocking,
dark interface and dark web pages, desktop-site mode, find in page, downloads,
print / save as PDF, fullscreen video, file uploads, popup blocking, text size,
long-press link and image menu, per-site location / camera / microphone prompts, reopen closed tab, default-browser support.

Build: push to `main`, then grab `Feather-apk` from the GitHub Actions run.
